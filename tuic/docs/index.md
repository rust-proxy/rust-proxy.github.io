# TUIC

通过 QUIC 连接应用与远端网络。

TUIC 为 TCP 和 UDP 流量提供代理通道。本手册介绍 **Itsusinn/tuic** 的独立服务端与客户端：在服务器上运行 `tuic-server`，在本机运行 `tuic-client`，再让应用使用本地 SOCKS5 代理。
